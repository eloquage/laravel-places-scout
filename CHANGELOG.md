## [1.0.0](https://github.com/eloquage/laravel-places-scout/releases/tag/v1.0.0) - 2026-10-23

### Added

- Initial release
- Text Search API support with pagination
- Place Details API support
- Strongly typed DTOs (PlaceSearchResponse, PlaceSearchResult, PlaceDetails)
- Fluent API for overriding API keys per request
- Laravel 12 and 13 support
- PHP 8.3+ requirement
- PHPStan Level 5 static analysis
- GitHub Actions CI for tests, PHPStan, and Laravel Pint

## [v1.0.1](https://github.com/eloquage/laravel-places-scout/compare/v1.0.0...v1.0.1) - 2026-11-03

Release the package with Composer identity under the eloquage vendor namespace. This release contains the package metadata and documentation rename; runtime behavior is unchanged.
